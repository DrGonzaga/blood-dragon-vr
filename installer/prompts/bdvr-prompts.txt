; ================================================================
;  BLOOD DRAGON VR - IN-GAME PROMPT TEXTS
;  Lives in the game's bin folder next to fc3vr.ini. The mod reads it at start
;  and again whenever you save it (even with the game running).
; ================================================================
;
;  Lines starting with ; are notes and are ignored.
;
;  PART 1 - BUTTON NAMES
;  The game writes buttons as tokens like [Reload]. On screen the game swaps
;  each token for a picture of the flat-screen pad button. Give a token a name
;  below and every text that uses it shows your name instead, for example
;      [Reload] = B      turns "HOLD [Reload] TO RELOAD" into "HOLD B TO RELOAD"
;  Leave a name empty to keep the game's button picture.
;  The names below are the defaults for the shipped button layout.
;
;  PART 2 - WHOLE TEXTS
;  Every game text that mentions a button, grouped as the game files group them.
;      #56331  SP_Actions_Reload       <- the text's number and name (don't change)
;      GAME: [Reload] RELOAD           <- what the game says (for reference only)
;      VR:                             <- write your own text here
;  An empty VR: line keeps the game's text (with the button names from part 1).
;  Your VR text can be any length and can still use tokens like [Reload].
;  \n starts a new line. Bits like <font color="#94ffa8">...</font> colour words
;  and <img .../> show a small icon; keep them or delete them as you like.
;  Some texts are never shown in the PC game (console or old versions): the
;  numbers that do appear are listed in fc3vr.log as "prompts: text <number>".
